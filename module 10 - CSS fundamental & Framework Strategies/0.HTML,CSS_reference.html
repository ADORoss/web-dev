Rules of thumb - Default tag styling → element - Reusable component or a style that could appear several times → class - Something that appears exactly once (logo, nav, footer) → id - JavaScript needs it → id - Can't decide? → class (safest, most flexible) Important: you CAN'T just use whatever you want 1. IDs must be unique — two elements can't share the same id. 2. Classes can repeat — many elements can share a class. 3. CSS conflict order — if both apply, ID beats class beats element: p { color: blue; } /* loses */ .card { color: green; } /* loses */ #x { color: red; } /* wins */ Quick rule: element = all, class = a group, id = exactly one.
